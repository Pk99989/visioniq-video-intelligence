# Phase 3 benchmark — 2026-11-06

Computer-vision calibration, tracking, and trajectories, measured on
this machine (Linux VM, CPU-only YOLOv8n ONNX, `CPUExecutionProvider`).
Ground truth is hand-estimated boxes (see `scripts/benchmark.py`
`GROUND_TRUTH`); IoU threshold 0.5.

## Detection precision / recall (IoU >= 0.5)

| Image | Precision | Recall | TP | FP | FN |
|---|---|---|---|---|---|
| bus.jpg (810x1080) | **0.80** | **0.80** | 4 | 1 | 1 |
| traffic frame, t=5s (1280x720) | **0.67** | **0.50** | 2 | 1 | 2 |

Notes:

- bus.jpg: YOLO predicts 4 persons + 1 bus (conf 0.57–0.90). The FP
  and FN are most likely the same partial person at the left edge —
  my ground-truth box for that sliver is narrow, YOLO's box is wider,
  so their IoU falls below 0.5 and it counts as both a miss and a
  false alarm. The 3 fully-visible persons and the bus all match
  (IoU 0.53–0.85).
- Traffic frame is genuinely hard: heavy occlusion, small and
  partial vehicles at the edges. YOLO predicts bus 0.75, truck 0.49,
  bus 0.48 — 3 of the 4 labelled vehicles, missing the far-right
  partial bus and one more, with 1 false positive. These are small
  (2-frame) numbers: direction, not a claim about general accuracy.
- No face or identity recognition is implemented or measured anywhere
  in VisionIQ; detection is COCO object classes only.

## Tracking

- **Track stability: 0 id switches** over 3 repeated frames of the
  same image (ids [1,2,3,4,5] on every frame).
- **Trajectories (live, moving-traffic video):** 16 tracks via
  `GET /videos/{id}/trajectories` — e.g. bus track 6, 5.0s → 12.5s,
  dwell 7.5s, 10 frames, 340.1 px displacement; car track 11,
  dwell 4.0s, 304.8 px. Cross-user request returns 404.
- Tracker is now per-video (no shared global state); tracks retire
  after `YOLO_TRACK_MAX_MISSED=5` unseen frames or
  `YOLO_TRACK_MAX_AGE_SECONDS=120`.

## Latency and execution provider

- **Mean per-frame latency: 219.8 ms** (warm session, 2 images).
  Earlier 456–880 ms/frame figures included cold session load.
- **Execution provider: CPU** on this VM — `onnxruntime` here has no
  CUDA provider, so the CUDA-first config falls back to CPU as
  designed. GPU latency on the RTX 3050 is still unmeasured; it
  needs a run on the user's laptop.

## Config used

`YOLO_CONF=0.35`, `YOLO_NMS=0.45`, `YOLO_CLASSES=` (all),
`YOLO_MIN_TRACK_IOU=0.3`, `YOLO_TRACK_MAX_MISSED=5`,
`YOLO_TRACK_MAX_AGE_SECONDS=120`, `YOLO_EXECUTION_PROVIDERS=CUDA,CPU`.
All are env-overridable and reported by `/health` under `detection`.
